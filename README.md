# 🦅 Eagle — محلل ومسّاح الأسهم (مصر + أمريكا + الإمارات)

أداة دعم قرار (Decision Support Tool) لتحليل الأسهم فنياً ومالياً، مبنية بـ
Streamlit، بتغطي البورصة المصرية (EGX) والأمريكية (US) والإماراتية
(DFM/ADX)، بالإضافة لتحليل فني للعملات الرقمية والمعادن والعملات الأجنبية.

> ⚠️ **تنبيه مهم:** الأداة دي للمساعدة في اتخاذ القرار بس — **مش توصية
> شراء/بيع، ومش ضمان ربح**. أي قرار استثماري نهائي مسؤولية المستخدم
> بالكامل. راجع قسم "حدود الأداة وGAPs" تحت قبل الاستخدام الفعلي.

---

## 1) الفكرة الأساسية

النظام مبني حوالين مبدأ واحد اسمه **Single Source of Truth**: كل منطق
حساب المؤشرات الفنية (EMA, RSI, MFI, ADX, ATR, بولينجر, الدعم/المقاومة)
ونظام التقييم (Eagle Score) موجود في **ملف واحد فقط** (`eagle_core.py`)،
وكل باقي الملفات (التطبيق الحي، محرك الـBacktest، محركات التحليل
الإضافية) **بتستورد نفس الدوال بالهوية** (`is` لا `==`) — يعني مستحيل
هندسياً إن يبقى فيه نسختين من نفس المنطق تنحرف عن بعضها بمرور الوقت.
ده مُثبَت باختبارات هوية صريحة (`test_production_backtest_score_consistency.py`).

---

## 2) خريطة الملفات

### النواة (Core)
| الملف | المسؤولية |
|---|---|
| `eagle_core.py` | **المصدر الوحيد** لكل المؤشرات الفنية + نظام Eagle Score (تقييم السهم من 100) + Data Confidence + Signal Conflict Detection + Final Decision Engine. |
| `final_bot.py` | تطبيق Streamlit الرئيسي (الواجهة الحية) — فيه كل التابات (فحص سهم، مسح السوق، المحفظة، الأسواق العالمية، الأرشيف التاريخي). |
| `backtest_engine.py` | محرك اختبار الاستراتيجية على بيانات تاريخية حقيقية — بيستورد دوال `eagle_core.py` مباشرة (نفس الهوية). |

### محركات إضافية (Phase 1.7A وما بعده)
| الملف | المسؤولية |
|---|---|
| `price_behavior_engine.py` | **Phase 1.7A** — يحسب شدة التغيّر السعري، ثبات السعر، خطر استمرار الاتجاه الهابط، واحتمال Falling Knife / Bottom Trap. Context إضافي في Decision Card فقط — **لا يؤثر على Eagle Score** (معطّل افتراضياً عبر `ENABLE_PRICE_BEHAVIOR_SCORE_ADJUSTMENT = False`). |
| `sector_historical_archive.py` | يبني مؤشر قطاعي مجمّع (Equal-Weighted) من كل أسهم القطاع (أو أصل عالمي واحد مثل BTC/الذهب)، ويكتشف نوافذ الصعود والنزول التاريخية + تحليل موسمية شهرية (أي الشهور كانت صاعدة تاريخياً). |
| `egx_historical_analyzer.py` | تحليل موسمية وسلوك تاريخي عام (شهري، أيام متتالية، أيام الأسبوع) — دواله عامة وبيُعاد استخدامها من `sector_historical_archive.py`. |
| `sp500_gics.py` | بيانات مرجعية بس (GICS Sector لكل سهم S&P 500 من Wikipedia) — استُخدمت لتصحيح تصنيف القطاعات في `final_bot.py`، مش جزء من منطق التطبيق وقت التشغيل. |

### الاختبارات (Tests)
| الملف | بيغطي |
|---|---|
| `test_production_backtest_score_consistency.py` | إثبات الهوية بين `final_bot.py` و`backtest_engine.py` و`eagle_core.py` (نفس الـfunction object بالذاكرة). |
| `test_price_behavior_engine.py` | 22+ اختبار لمحرك Phase 1.7A (مع تشغيل الـRegression tests القديمة تلقائياً). |
| `test_sector_historical_archive.py` | 24 اختبار لمحرك الأرشيف القطاعي + الموسمية. |
| `test_egx_historical_analyzer.py` | اختبارات الموسمية والتحليل التاريخي العام. |

### بيانات مرجعية (CSV)
`egx_sectors.csv`, `us_stocks.csv`, `uae_stocks.csv` — قوائم الأسهم وتصنيفاتها القطاعية لكل سوق.

> ℹ️ ملفات زيادة موجودة في الـrepo (`app.py`, `data_providers.py`,
> `egx_screener.py`, `egx_screener_app.py`) مش جزء من الـpipeline اللي
> موصوف هنا — راجعها لوحدها لو محتاج تفاصيلها.

## 3) أهم الميزات

### 🔍 فحص سهم تفصيلي (Tab 1)
تحليل فني كامل لسهم واحد (EMA9/21، RSI، MFI، ADX، بولينجر، دعم/مقاومة، حجم
وRVOL) + فاندمنتال (P/E، جراهام) + **Decision Card** تفسيرية + Price
Behavior Context (Phase 1.7A) + بادچ الزخم متعدد الآجال.

### 🏆 مسح وترتيب السوق (Tab 2)
مسح شامل لكل الأسهم في السوق المختار، مقسّمة لأربع فئات أساسية (تأسيس
مركز جديدة / تصيد قيعان / مضاربة لحظية / استثمار طويل) + **سادساً: الزخم
متعدد الآجال** (بداية صعود اليوم / صعود أو نزول متسق يومي+أسبوعي+شهري).

### 🌍 الأسواق العالمية (Tab 4)
أسعار لحظية لفوركس/كريبتو/معادن/طاقة + **تحليل فني ومالي تفصيلي** لأي أصل
منهم (نفس مؤشرات الأسهم العامة + Price Behavior Context + فاندمنتال
مكافئ لكل نوع أصل، مع توضيح صريح لما لا ينطبق).

### 🗄️ الأرشيف التاريخي للقطاعات (Tab 5)
- **أرشيف نوافذ الصعود/النزول**: "من تاريخ X لتاريخ Y، القطاع كله صعد/نزل
  كام %" — لكل قطاع في مصر/أمريكا/الإمارات، أو لأصل عالمي واحد
  (كريبتو/معدن/عملة).
- **🔮 توقع موسمي**: تحليل تاريخي لأي الشهور كانت صاعدة في أغلب السنين
  السابقة لكل قطاع/أصل، مُرتَّب تنازلياً — **ميل إحصائي تاريخي، مش تنبؤ
  مضمون**.

```bash
pip install -r requirements.txt
streamlit run final_bot.py
```

للنشر على Streamlit Cloud: تأكد إن كل الملفات أعلاه موجودة في نفس مستوى
`final_bot.py` بالـrepo، وبأسماء **snake_case بالضبط** (بدون مسافات أو
حروف كابيتال)، وإن `requirements.txt` فيه `streamlit`, `pandas`, `numpy`,
`plotly`, `yfinance` على الأقل.

```bash
python test_production_backtest_score_consistency.py
python test_price_behavior_engine.py
python test_sector_historical_archive.py
python test_egx_historical_analyzer.py
```

> بعض الاختبارات (اللي بتعمل `import final_bot`) محتاجة `streamlit`
> مُنصَّبة فعلياً لتعمل بالكامل — لو مش متاحة، بتتخطى (`SKIPPED`) بهدوء
> وتوضّح السبب، وباقي الاختبارات (static checks + identity على
> `eagle_core`/`backtest_engine`) كافية لإثبات عدم وجود نسخ منطق مكررة.

## 6) مبادئ تصميم مهمة (لازم تُحترم في أي تعديل مستقبلي)

1. **Single Source of Truth** — أي مؤشر فني أو منطق تقييم جديد يروح في
   `eagle_core.py` بس، وكل الملفات التانية تستورده (مش تعيد حسابه).
2. **Point-in-Time Discipline** — أي دالة بتحلل سهم/قطاع لازم تستخدم
   بيانات لحد لحظة معينة بس (صفر `shift(-N)`, صفر `center=True`) — مُختبَر
   صريح بـ `test_no_lookahead`.
3. **معطّل افتراضياً حتى يُثبَت نافعاً** — أي طبقة تحليل جديدة (Phase
   1.7A مثلاً) بتبدأ كـContext للعرض بس، بدون تأثير على Eagle Score أو
   القرار النهائي، إلا بعد Backtest مستقل يثبت الفايدة إحصائياً.
4. **GAP موثّق بصراحة، مش تخمين** — لو بيانة مش متاحة أو تحليل مش منطقي
   لنوع أصل معين (زي فاندمنتال لعملة أو فوركس)، بيُقال صراحة في الواجهة
   بدل تلفيق رقم.
5. **درجة الثقة مُعروضة مش مخفية** — أي نتيجة مبنية على عيّنة بيانات صغيرة
   (تاريخ قصير، سنين قليلة) بتُعلَّم بوضوح ("⚠️ عيّنة صغيرة")، مش تُعرض
   كمؤكدة وهي مش كذلك.

## 7) حدود الأداة وGAPs معروفة (مهم تقراها)

- **تصنيف القطاعات**: تم تصحيحه بدقة للقطاع الطبي في الأسواق التلاتة،
  وبشكل شامل لأمريكا (عبر GICS Sector الرسمي من Wikipedia). **الإمارات
  لسه محتاجة تدقيق شامل لباقي القطاعات** (غير الطبي) — مفيش مصدر واحد
  موثوق شامل زي Wikipedia للإمارات حالياً.
- **التوقع الموسمي ليس تنبؤاً** — هو ميل إحصائي تاريخي بحت (نسبة السنين
  الصاعدة في شهر معين)، ومينفعش يُستخدم كقرار استثماري مستقل.
- **الفاندمنتال للأصول غير الأسهم** — مفيش مكافئ حقيقي لـP/E أو جراهام
  لعملة رقمية أو زوج عملات أو عقد سلعة آجل؛ المعروض هو أقرب مكافئ فعلي
  متاح بس (Market Cap للكريبتو مثلاً)، والباقي GAP موثّق صراحة.
- **محتاج إنترنت فعلي وقت التشغيل** — أي تحليل تاريخي (Backtest، الأرشيف
  القطاعي، التوقع الموسمي) محتاج جلب سنين من بيانات الأسعار الحقيقية.
- **الأداء**: حساب التوقع الموسمي لقطاعات كبيرة (زي أمريكا) بياخد وقت —
  فيه حد أقصى افتراضي (عيّنة 15 سهم لكل قطاع) قابل للتعديل من الواجهة.

## 8) إخلاء مسؤولية

هذا النظام أداة دعم قرار تعليمية/تحليلية، **ليست نصيحة مالية أو استثمارية**،
ولا تضمن أي عائد أو دقة تنبؤية. الأسواق المالية بطبيعتها غير مضمونة،
والأداء التاريخي لا يضمن تكرار النتائج في المستقبل. المستخدم مسؤول بالكامل
عن أي قرار استثماري يتخذه.
